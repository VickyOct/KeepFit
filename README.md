# KeepFit

一款简约的手机饮食与训练记录 App，记录每日蛋白质摄入和每次健身内容。

## 第一版功能

- 使用相机拍照或从相册选择餐食照片
- 忘记拍照时可直接手动新增一餐
- 显示明确标注的演示识别建议
- 按分类浏览 51 种中文常用食物
- 搜索 USDA FoodData Central 在线食物营养库
- 找不到的食物可按包装营养表手动添加
- 添加或移除食物
- 以 10 克为单位调整食物份量
- 自动估算每餐和每日蛋白质
- 修改每日蛋白质目标
- 每天 09:00、12:00、18:00 发送本地饮食记录提醒
- 将饮食记录保存在当前设备
- 查看及删除历史记录

## 三餐食谱

底部点击「食谱」默认浏览 12 道基础粤菜与茶餐厅菜单：炒蛋多士、火腿通粉、餐蛋面、吞拿鱼三文治、干炒牛河、豉油皇炒面、番茄炒蛋饭、冬菇蒸鸡饭、蒸水蛋、姜葱蒸鱼、虾仁炒蛋、榨菜蒸肉饼。按普通家常做法整理，不以减脂筛选。卡片标出每份大概卡路里，详情说明是否含米饭与配餐、逐食材估算依据；切换 1 / 2 / 4 份时同时显示整锅总热量。原来的 15 道菜和收藏保留在「原有食谱」。

支持餐次、菜系、20 分钟内、收藏筛选和食材搜索。内容离线可用，收藏保存到当前设备；外部来源需联网。热量由页面配方计算并取整：部分食材使用 USDA 数据，部分使用标明的编辑近似值；不代表餐厅实测热量。原有食谱仍标明未核算，收藏不会自动写入饮食记录。说明见 [粤菜与茶餐厅菜单](docs/cantonese-menu.md) 与 [原有食谱来源](docs/recipe-sources.md)。验证：`npm.cmd run test:recipes`。

## 健身记录

底部点击「健身」进入训练页面。可浏览 50 个动作，按中英文动作名、常见别名、器材名搜索或按训练部位筛选；点击动作查看步骤、发力要点、常见错误和可点击的技术参考。30 个原有动作有离线配图，20 个新增动作明确标注为文字参考。

在「动作与器材库」点击「三张健身图，哪些说对了？」可查看腿臀、背部和正面三张图的核对结果，并直接打开相关动作指导。肌群说明区分训练侧重与共同参与；参考来源区分社区动作资料、ACE 技术/解剖说明和研究证据。图中文字不明确的动作会明确说明，避免猜测成确定技术。

20 个动作带有「女性友好候选」标签，可与部位、名称一起筛选。标签表示可按个人身体比例、关节活动与器械尺寸进一步匹配，分为「可自选轨迹」「可调站位」「需匹配器械」；详情列出具体理由、适用条件与来源。它不是“已证明对女性骨骼更好”的性别排名，也不是新手难度或练臀效果排名。未标注的动作不代表不适合女性。筛选原则见 [身体适配标注](docs/female-friendly-fit.md)。

点击「开始训练」添加动作，逐组填写重量（kg）与次数，计时动作填写秒数，并勾选已完成的组。保存只计入已完成的组；未完成的组不会被当成实际训练。自重动作的重量填写 0，哑铃重量按单只填写，杠铃按含杆的总重量填写。有氧时长作为记录输入，不会自动感知运动。

训练草稿和已保存的记录保存在手机本地，切换页面或重新打开 App 后可以继续。历史记录可查看逐组明细和备注，支持确认后删除。找不到的动作可以自定义录入；自定义动作没有预设图解。

动作文字和已有示范图片随 App 打包，查看不需要额外 API 或联网；打开外部参考链接需要联网。图片与内容来源说明见 [动作资料来源](docs/exercise-sources.md)，逐图核对见 [三张健身图核对](docs/exercise-diagram-review.md)。

开发检查：`npm.cmd run typecheck`、`npm.cmd run test:workouts`。

## 篮球裁判学习

底部点击「裁判」阅读 FIBA 2026 中文学习课程，共 16 课、119 节详细讲解与案例、160 道情境题。正文包含规则条件、例外、判罚理由和易错点，覆盖每课全部测验考点；目录可跳转，错题解析可直接回看对应讲解。每课读完点击「标记为已完成」解锁 10 道单选测验；8 / 10 为本模块复习门槛，支持重做。课程列表可搜索，按未完成、已完成或待巩固筛选；阅读进度、答题草稿、最近和最高成绩保存在当前设备。

内容依据你提供的 2026 年 8 月 v1.0 官方解释，2026-10-01 起适用，采用中文要点讲解与原创练习，并非官方逐字译本或完整官方培训课程。每节「对应英文原文」可在网页内展开官方 PDF，对照条款和页码；测验解析也可跳到对应英文依据。中文学习和答题可离线使用，英文原文需联网，内嵌或自动定位失败时可用原文链接单独打开。课程范围及版本说明见 [裁判学习模块](docs/referee-learning.md)。检查：`npm.cmd run test:referee`。

课程最后新增 5 套综合情景测试，每套 10 题，额外共 50 题。选择完整临场处理：是否吹哨、判什么、罚球、球权及计时；包含合法动作应继续的情况。每套分别保存草稿、最近和最高成绩，可续答、重做和只复习错题；解析能回到相应课程和英文原文，再返回测验。建议读完 16 课后练习，也可直接开始。综合记录加入网页版备份，原课程进度保留。

## 在 Expo Go 中运行

```bash
npm install
npx expo start
```

确保电脑与手机处于同一网络，然后使用 Expo Go 扫描终端中的二维码。

首次打开更新后的版本时，请允许 Expo Go 或 KeepFit 发送通知。提醒按照手机当前时区运行；首页会显示提醒是否已开启。

Expo Go 测试期间，需要电脑保持 Expo 开发服务运行。制作并安装独立测试版或商店版后，日常记录和本地提醒无需电脑即可运行；在线食物搜索仍需要网络。

## 手机网页版（无需苹果开发者会员）

使用 Safari 打开已发布的 HTTPS 网址，通过「分享 → 添加到主屏幕」安装。电脑无需开机。首次联网打开后，首页显示「离线内容已就绪」才表示页面、食谱、课程与动作图片已缓存；在线食物搜索仍需联网。更新会在关闭全部 KeepFit 页面并重新打开后生效。

- 饮食、照片、训练草稿、收藏与学习进度通过 IndexedDB 保存在当前浏览器；无账号同步，不会自动读取 Expo Go 的旧数据。
- 照片在保存前缩小为最长边 1280 像素的 JPEG，刷新页面后仍能读取。
- 首页提供「导出备份」和「恢复备份」。恢复前校验内容并请求确认，整份备份在同一个数据库事务中写入；失败不覆盖原数据。备份包含个人记录和照片，请妥善保存。
- 清除网站数据、卸载主屏幕应用、隐私浏览或系统存储清理可能导致数据丢失。建议安装后固定在主屏幕入口使用，并定期导出备份。不同域名的记录不互通。
- 网页版暂不提供关闭页面后的定时通知，可使用 iPhone 的「提醒事项」。拍照与选图由浏览器/系统提供，需在真机上授权和验证。

开发运行：`npm.cmd run web`。生产构建：`npm.cmd run build:web`。本地检查构建产物：`node scripts/serve-web.cjs`，访问 `http://localhost:8085`；手机局域网 HTTP 仅用于临时预览，不支持安全上下文要求的离线安装能力。

检查：`npm.cmd run typecheck`、构建后 `npm.cmd run test:web`，以及已有的 workouts / recipes / referee 测试。

部署源副本保存在 `.expo/keepfit-site`，其中 `.openai/hosting.json` 记录 Sites 项目身份。发布时复制当前源文件与 `dist`，保留该身份，通过 Sites 工作流保存并发布；不上传 `.env`、开发日志或设备数据。

## 在线食物库

开发测试默认使用 USDA 提供的 `DEMO_KEY`，不需要额外设置，但免费额度较低。需要更高额度时，可申请 data.gov API key，并在本机新建 `.env.local`：

```text
EXPO_PUBLIC_USDA_API_KEY=你的测试Key
```

注意：`EXPO_PUBLIC_` 变量会进入手机 App，不能用于正式发布时保存私密 Key。生产版本应通过自己的后端转发 USDA 请求，避免公开 Key。

## 当前限制

`src/services/foodRecognition.ts` 目前返回清楚标注的演示结果，不会假装已经分析了照片。下一步可在这一层连接自托管 Food-101 模型或其他食物识别服务，界面不需要重写。

内置和在线食物营养数据都是参考值，不能替代专业营养或医疗建议。照片 URI 与记录保存在当前设备；系统清理缓存后，旧照片预览可能失效，但文字记录仍会保留。

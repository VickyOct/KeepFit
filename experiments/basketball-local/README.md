# Wolf 7 号：本机视频试验

已在本机完成推理试验，未使用付费云端算力，也没有训练新模型。

正确比赛：[20260630 NWL 4v4 Game 3 Full - Snow White vs Wolf](https://www.youtube.com/watch?v=sYWx1qcIapE)。用户提供的身份参考是原视频 **31:19 的红衣 7 号罚篮**。

## 打开校对结果

双击本目录的 `Open-Review.cmd`，或打开 [本机校对页面](http://127.0.0.1:8768/review.html)。页面显示 **30:30–32:30** 的片段，默认停在 31:19。服务只监听本机 127.0.0.1:8768。

1. 点击“31:19 罚篮参考点”。绿色参考框对应用户指出的罚篮球员。
2. 下方第一张轨迹卡是该参考点对应的 T294（31:13–31:35）。查看截图与整段视频后，可人工关联到 7 号。关联依据是用户给出的罚篮球员，尚未做球衣号码 OCR。
3. 观看并选择已核对的事件类型，再点“确认并计入 7 号”。可以补录、编辑、移除或撤销。
4. 校对结束后点击“导出校对结果”留存 JSON。浏览器内的记录只存在该浏览器的本地存储中，清除浏览器数据会丢失。

统计默认显示横线；没有经过校对的数据不是零次。罚球与运动战出手分开统计，助攻不增加出手次数。未做比赛规则自动裁决，犯规、违例与有效得分需要人工判断。

2026-09-10 修复了内嵌浏览器中“只有追踪框、视频黑屏”的显示问题：视频与追踪框现在在同一画布绘制，并在暂停跳转后的首帧到达时刷新；加载和解码失败也有明确提示。实际验证了首次停在 31:19、截图跳转到 30:36.5、播放、暂停、前进和隐藏追踪框。人工关联与事件的存储键保持不变。

## 实测结果（2026-09-09）

设备：i7-12700H，约 16GB RAM，Intel Iris Xe 核显。实际推理使用 CPU 6 线程；模型输入最长边 960 像素，源视频 1920×1080。下表耗时为视频处理循环，不含安装、下载和首次模型加载。

| 试验 | 范围 | 采样频率 | 分析帧数 | 处理耗时 | 结果 |
| --- | --- | --- | --- | --- | --- |
| 首轮速度基线 | 05:00–10:00 | 约 5 帧/秒 | 1499 | 104.27 秒 | 人与球共用 ByteTrack；篮球仅在 14 帧中保留下来，未形成提示 |
| 罚篮参考片段 | 30:30–32:30 | 约 10 帧/秒 | 1199 | 102.80 秒 | 人物使用 BoT-SORT 与镜头运动补偿，篮球保留原始检测；544 帧出现篮球框，50 条自动提示 |

第二轮另加入了 **1 条用户提供的罚篮参考**，它不是模型自动发现的事件。默认红衣筛选显示 17 条自动提示加这一条参考。

两个试验的片段、采样率和处理方法不同，因此不能用这两组比例衡量准确率提升。篮球出现比例（第二轮为 45.37%）是“采样帧中出现至少一个篮球检测框”的比例，不是检测准确率、召回率或出手识别率；框中可能存在误检。

第二轮仍产生 202 段人物轨迹（包含双方球员、裁判和其他人物），这不是球员人数。镜头移动和遮挡会造成轨迹中断或换人。T294 在参考点定位正确，但不能据此证明整段、整场身份追踪正确。

**已验证：** 本机推理速度、实际人物/篮球检测、参考点到轨迹的人工关联、带时间点的视频校对、人工统计计算。

**尚未实现：** 自动号码识别、跨轨迹/跨场身份合并、可靠投篮分类、篮筐与命中判断、自动助攻。自动提示只是“球接近某人的上半身”，可能是接球、传球或投篮，也会漏掉实际出手。结果中没有自动生成的得分或助攻。

下一步优先用这两分钟做真实事件标注，逐条量化误报、漏报和身份交换，再决定训练球/篮筐检测与事件分类。当前资料尚不能给出模型准确率。

## 复跑（在本目录执行）

已安装的隔离环境位于 `.venv`，无需改动全局 Python。

```powershell
.\.venv\Scripts\python.exe analyze.py --video data/sYWx1qcIapE_1830_1950.mp4 --source-start 1830 --duration 120 --fps 10 --imgsz 960 --threads 6 --output runs/free-throw
.\.venv\Scripts\python.exe annotate_reference.py
.\start-review.ps1
```

复跑会替换该目录内的分析输出。若更换模型或轨迹配置，应使用新的输出目录，避免把旧人工关联用于新的轨迹编号。参考脚本会验证来源 ID，并在 31:19 寻找人工选定的罚篮球员位置；若画面或来源变化，不应沿用此参考。

首次搭建环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.14.0+cpu torchvision==0.29.0+cpu --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
```

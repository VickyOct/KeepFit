# 三张健身图核对

核对日期：2026-09-25。按用户上传文件编号，照片 1 是腿臀（原帖 3/3），照片 2 是背部（2/3），照片 3 是正面（1/3）。这里只核对名称、肌群与动作关系；图片没有动作过程，无法判断实际动作质量，也不是严格的解剖图。

结论：可以作入门动作索引，不能当作精准的“一个动作对应一小块肌肉”地图。共同参与、主要训练和可被单独隔离是不同概念。

## 照片 1：腿臀

| 图中内容 | 判断与修正 |
| --- | --- |
| 坐姿髋内收 | 主要训练大腿内侧髋内收肌群，不是大腿后侧腘绳肌专项。 |
| 髋外展、臀推、俯卧腿弯举 | 大致合理：分别偏髋外展肌群、臀大肌、腘绳肌；仍有其他肌肉参与。 |
| 杠铃深蹲、宽距深蹲 | 涉及股四头肌、臀大肌及内收肌群，不能只根据后视图位置理解成后侧或臀下缘训练。 |
| 罗马尼亚、直腿、相扑硬拉 | 都是多肌群动作；髋铰链涉及臀与腘绳肌，相扑式也有明显伸膝需求。“直腿”不要求锁死膝盖。 |
| 史密斯、哑铃站姿提踵 | 两者均涉及腓肠肌和比目鱼肌，不能按器械把它们分成两块小腿肌肉。屈膝坐姿是另一个重要变式。 |
| 山羊挺身 | 采用髋铰链做法时，臀、腘绳肌与竖脊肌共同参与。 |

依据：[ACE 髋、膝、踝肌肉功能](https://www.acefitness.org/fitness-certifications/ace-answers/exam-preparation-blog/3594/muscles-that-move-the-leg/)、[ACE 髋外展肌](https://www.acefitness.org/resources/everyone/blog/7335/enhance-your-running-game-by-strengthening-your-hips/)、[站姿与坐姿提踵训练研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10753835/)。具体变式资料见动作页的固定版本来源。

## 照片 2：背部

| 图中内容 | 判断与修正 |
| --- | --- |
| 冈下肌、小圆肌 → 高位下拉 | 误导。下拉主要涉及背阔肌、大圆肌和肘屈肌；冈下肌、小圆肌是肩袖外旋和稳定肌，不是下拉的主要专项训练对象。 |
| 三角肌 → 面拉 | 过粗。主要侧重后束和上背；带外旋的变式涉及肩袖，不能代表整个三角肌训练。 |
| 斜方肌 → 坐姿划船 | 不完整。还涉及背阔肌、菱形肌和肘屈肌，肘部路径会改变侧重。 |
| 反手杠铃划船 → 背阔肌 | 能训练背阔肌，但不会隔离图中画出的下方区域。 |
| 竖脊肌 → 山羊挺身 | 能参与，但髋铰链变式不是只练腰部。 |
| 提拉 | 名称不够具体；app 明确按直立划船提供参考，不能直接套用到高拉等变式。 |

依据：[ACE 高位下拉教程](https://www.acefitness.org/resources/everyone/exercise-library/158/seated-lat-pulldown/)、[ACE 肩关节与肩袖功能](https://www.acefitness.org/certifiednewsarticle/2660/a-commonsense-approach-to-addressing-shoulder-instability/)。

## 照片 3：正面

| 图中内容 | 判断与修正 |
| --- | --- |
| 上斜、平板、双杠分别对应上、中、下胸 | 可有区域侧重，不能理解成完全隔离；前肩和三头肌也参与。 |
| 卷腹 → 上腹，悬垂举腿 → 下腹 | 不能如此绝对划分。腹直肌连续，举腿还涉及髋屈肌；骨盆控制与动作范围影响刺激。 |
| 耸肩、前平举、侧平举、推肩 | 大体可作索引，但前、中、后束要区分，也不能忽视协同肌和肩胛运动。 |
| 弯举、锤式弯举、颈后臂屈伸 | 大体合理；不同肘屈肌会共同参与。正握弯举也不是全部前臂功能训练。 |
| 腹侧小字 | 疑似“侧提膝/侧提胯”，分辨率不足以确定具体变式；app 另列哑铃侧屈参考，未把两者当作同义词。 |

依据：[卧推角度与区域肌肉募集研究](https://pubmed.ncbi.nlm.nih.gov/36334406/)、[ACE 腹部训练说明](https://www.acefitness.org/resources/pros/expert-articles/8989/crunch-time-an-evidence-based-approach-to-training-the-abs/)。该卧推研究反映小样本急性肌电/超声反应，不能直接保证长期增肌结果。
